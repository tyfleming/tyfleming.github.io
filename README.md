# Ty Fleming

A small static research website for Ty Fleming, Imaging Science PhD student at Washington University in St. Louis.

## Pages

- `index.html` — introduction
- `research.html` — project overview
- `filo.html` — spatial neuroimaging methods
- `sleep.html` — sleep decoding workflow and probability simplex
- `publications.html` — prior publications and ongoing work
- `about.html` — background and contact

The site uses plain HTML and CSS, local JavaScript for the simplex and math rendering, and a pinned KaTeX release for the sleep equations. The FILO page includes paired cortical input maps from the ongoing analysis, credited in its caption.

The sleep simplex loads `assets/sleep-probabilities.json`: 9,121 subject-held-out, calibrated four-stage probability vectors from `evaluation_protocol/nested_cycle_tangent_blend/oof_probabilities.npz` on ml-sys-1. The static export has four probabilities per row and no participant, session, window, path, or observed-stage identifiers. Rows represent overlapping causal windows, so they are not independent samples.

The Sleep Decoding page reports pooled participant-held-out window-level performance computed from those two public exports. Run `python3 scripts/summarize_sleep_performance.py` to reproduce accuracy, balanced accuracy, macro F1, per-stage precision/recall/F1, and the confusion matrix. The script validates the label file against the probability-file SHA-256 first. Windows overlap and are correlated, so these pooled scores are not scan-level or independent-cohort estimates.

The simplex also loads `assets/sleep-ground-truth.json` with `schema_version: 1`, the same four `stages`, `probabilities_sha256` matching the exact bytes of the probability JSON, and one integer `labels` value (0–3) per row. When validated, the page exposes a prediction/observed-stage color toggle and shows both labels in the readout. The observed labels were checked row-for-row against the saved experiment before export. The public sidecar contains only stage codes and the probability-file checksum; no participant, session, or window identifiers are included. Rows are grouped by participant and ordered by time within participant, so this public per-window pairing may reveal sleep architecture despite omitted identifiers; it was published with Ty Fleming’s explicit approval.

The fifteen published SVG method panels use section.figure numbers (for example, Figure 02.1 in `sleep-figure-02-01.svg`). Figures 02.1–02.3 are one exact illustrative four-parcel PCA calculation, including same-volume mean subtraction, the training residual reference and covariance, fitted eigenvectors, and per-volume scores. Figure 02.4 shows the reconstructed fold-fitted 41-parcel Default-network basis and held-out outputs. Figure 02.5 inventories the actual atlas community counts and the three signals each contributes. The atlas display uses an equal-axis projection. These panels are generated with `python3 scripts/build_sleep_visuals.py` from a local representative tensor export, excluded from this public repository, `assets/sleep-decoding-method-supplement.json`, and `assets/sleep-cycle-atlas-topology.json`. The method supplement contains a reconstructed aggregate fold-trained residual basis, six-channel excerpts of actual window shrinkage and lag geometry, and saved calibration values. It contains no participant, scan, time, observed-label, raw 333-parcel-series, or performance fields. The atlas file contains only public [Gordon parcellation](https://doi.org/10.1093/cercor/bhu239) geometry and the actual fixed six-nearest-neighbor graph derived from it; neighbor selection uses 3D MNI coordinates, and the SVG uses a 2D projection for display. Cycle features and probabilities are saved model outputs; cortical signals, SPD matrices, tangent features, and PCA scores are deterministic reconstructions using that held-out fold's frozen transforms. The sample covariance, eigenvalue spectrum, and pre-temperature blend are derived from the representative window. The time-window and individual edge-flow diagrams explain operations and are labeled schematic. To regenerate the panels, place the approved local export at `assets/sleep-decoding-representative.json` and run the script.

The home and research overview use the selected Night Oracle SVG portrait generated by `head-studies.js`. The unlinked `head-studies.html` page keeps alternate visual studies for comparison. These illustrations are not research data.

## Local preview

Run `python3 -m http.server 8000 --bind 127.0.0.1` in this directory and open `http://127.0.0.1:8000/`.

## Publishing

This repository should be named `tyfleming.github.io` and published from the root of the `main` branch through GitHub Pages. All links and assets are relative to the site root.
